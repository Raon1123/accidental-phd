## 목표

## 체크리스트

- [ ] 선택 민감도: 같은 seed에서 결정 지점별 선택지 교체 시 결과 분포 변화 측정. 완료 조건: 변화가 0이 아니고(선택이 의미 있음) 결정적이지도 않음(단일 선택이 결과를 100% 정하지 않음).
- [ ] 플레이테스트 3인 이상(인문사회 1, 이공 1 포함). 완료 조건: 피드백을 issue로 등록.
- [ ] 회고: Wave 1~5 회고 섹션 전부 채움, 다음 사이클 wave 파일 초안.

## 체크리스트

- [ ] 선택 민감도: 같은 seed에서 결정 지점별 선택지 교체 시 결과 분포 변화 측정. 완료 조건: 변화가 0이 아니고(선택이 의미 있음) 결정적이지도 않음(단일 선택이 결과를 100% 정하지 않음).
- [ ] 플레이테스트 3인 이상(인문사회 1, 이공 1 포함). 완료 조건: 피드백을 issue로 등록.

### Wave 4 보정에서 이관 (결정 기록 0015 §4)
출처: [wave-04 §체크리스트 "보정 하네스"](wave-04-engine-impl.md), 결과표 [calibration-wave4.md](../oracle/calibration-wave4.md) (N=1000, 2026-10-14). Wave 4는 스펙이 보정에 맡긴 항목만 바꿨다(0014 #45·#46·#61·#119). 아래는 허용 범위(0014 #52) 밖으로 남은 목표와 측정한 원인 후보다. 약어: KEDI = 한국교육개발원, KSCED = 한국표준교육분류([용어집](../workflow.md#용어집)).

- [ ] 재정 파탄 종료 비율: 기본 상수에서 자동 플레이의 85%가 약 2년 안에 `financial`로 끝난다(월 순현금 −89만~−182만, 대출 한도 소진 중앙 20개월). 원인 후보: 0014 #60 생활비 160/130만(100/80만이면 파탄 85%→64%), #23 장학 레코드 균등 추첨(16만~50만 소액 장학이 섞여 장학 경로 중앙 64.5만 vs 과제 110만), 과제 장려금이 법정 하한 레코드(`-stipend-min*`)인 점, §4.4 자동 정책에 근로 포커스가 없는 점. — 완료 조건: 기본 상수 자동 플레이에서 `financial` 종료가 30% 이하이고, 바꾼 0014 번호·새 값·근거가 0014 행과 결과표에 있다.
- [ ] 연간 이탈 비율: 재정 중립 모의에서 0.037/0.035/0.043/0.028(인문/사회/자연/공학)로 KEDI 중도탈락률 ±30% 하한 아래(공학·인문·사회). 원인 후보: 0014 #49 배경 이탈 비중 0.5 → 약 0.7. — 완료 조건: 재정 파탄이 정리된 뒤 4계열 모두 허용 범위 안.
- [ ] 학위 후 1년 안 취업 비율: 인문사회 0.86~0.93(목표 0.41~0.47), 이공 0.73~0.77(목표 0.59~0.68). 취업 정의는 시간강사·박사후를 포함(결정 기록 0013 §1)하므로 시간강사 h(0014 #106 상한 0.85)와 박사후·기업 h(#107·#110~#112)가 과대. 측정: 이공 `ROUTE_H` ×0.7이면 2/6 통과. — 완료 조건: 6계열 중 5계열 이상 ±0.10 안, 바꾼 번호와 값이 0014에 있다.
- [ ] 휴학 지표 정의: 선택권 §4.6 "연간 휴학 경험 비율"을 KEDI 레코드(휴학생÷재적, 스톡 비율)와 같은 정의인 "휴학 개월÷재학 개월"로 읽으면 4/4 통과(0.137/0.139/0.090/0.076), 12개월 창 정의로는 약 2.2배. — 완료 조건: 선택권 §4.6과 0014 #47에 정의 한 줄이 있고 결과표가 그 정의로 판정한다.
- [ ] 교수 경험 비율(보고만): 졸업 후 10년 안 교수 경험이 이공 0.09·인문사회 0.17(재정 중립)로 신규 임용÷학위 취득자 상한(약 0.64)보다 훨씬 낮다. 플레이테스트에서 체감을 확인하고 필요하면 #104 κ·상한을 본다.
- [ ] 자동 정책의 논문 시작 시점: §4.4 정책이 자격시험 전에는 초고를 만들지 않아 첫 투고 중앙 48개월. 플레이어 선택과 동기 분포가 다르면 #46에 합격 전 집필 규칙을 넣을지 판정.

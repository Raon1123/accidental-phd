# Wave 5 — UI·서사·가상 뉴스

## 목표
플레이 가능한 정적 사이트. 1in8b.life에서 상속한 UI 장치와 narratives 팩에 근거한 창작 서사.

## 진입 조건
Wave 4 종료 조건.

## 체크리스트
- [ ] 정적 사이트 골격(`web/`), GitHub Pages 배포, localStorage 저장·불러오기·기록 보관(최근 10개).
- [ ] 입학 전 선택 화면: 계열 → 전공군 → 세부전공(NRF) → 학교·학과 → 자금 → 지도교수 선호, 각 단계 "운에 맡기기".
- [ ] 1in8b.life 상속 UI: 속도 조절(1×~16×), 자동 모드, 연구노트(기록, 최신순), life map(1칸=1개월 또는 1년), 결정 지점에서 시간 정지.
- [ ] "같은 해 입학한 동기 4명" 패널과 "다른 선택 보기" 분기 화면.
- [ ] 서사 텍스트 팩: narratives 팩 레코드에 근거한 학과·계열별 장면 텍스트(창작 표시). 완료 조건: 모든 장면이 narratives 레코드 id 또는 `assumed`를 참조.
- [ ] 가상 분야 뉴스 텍스트 팩: 계열·분야별 월간 헤드라인과 수요 효과 태그(창작 표시). 완료 조건: 뉴스마다 효과 크기·지속 기간이 Wave 3 결정 기록 범위 안.
- [ ] 가상 학교명 표시 함수: 화면·공유 카드·로그에 실명이 나가지 않는 테스트(결정 기록 0004).
- [ ] 출처 footer: registry.json에서 자동 생성.
- [ ] 접근성: 키보드 조작, 본문 건너뛰기, 명도 대비.

# 0002. 픽셀 장면과 삽화

## 가설
지금 화면은 글자와 막대뿐이라 단계가 바뀌거나 큰 사건이 생겨도 화면 인상이 같다. 단계 배경과 사건 삽화를 8-bit 픽셀로 넣으면 지금 어디에 있는지와 무슨 일이 있었는지가 한눈에 들어오고, 글자 정보는 그대로 남는다.

## 변형
시안 페이지(비공개 Artifact, 소유자만 열람): https://claude.ai/artifact/XDgZp2Z9LSGSUSJDf1ziv5 — 저장소 코드는 바꾸지 않은 비교용.
- a: 상단 장면 창. 제목 아래 가로 장면, 인물 말풍선에 최근 사건, 아래 대화 상자.
- b: a + 연구노트 줄마다 픽셀 아이콘.
- c: 화면 전체 배경 풍경, 카드는 불투명하게 위에.
- d: 넓은 화면 왼쪽 칸 초상 창.
- e: 모두 함께. 역할을 나눠 d(지금 상태) + b(사건 종류) + c(여백 분위기) + a(큰 사건 때만), 좁은 화면은 따로 설계(고정 상태 줄, 아래 알림 막대, 자금 카드 접기).

## 측정
- 자동: `pixel.test.ts`, 대비 시험, 넓은 화면·390px에서 가로 넘침 없음.
- 사람: 단계와 최근 사건이 그림으로 바로 읽히는가, 글자 정보를 가리지 않는가, 휴대폰에서 첫 화면이 지나치게 길어지지 않는가.

# 0001. landing 배치

## 가설
시작 화면에서 돈 패널(`#money`)이 비어 있는 동안에도 왼쪽 20rem 열이 비어 있어, 제목은 왼쪽 끝에 있고 분야 선택은 그 오른쪽에 떨어져 보인다. 빈 열을 접으면 제목과 선택이 한 줄에 놓여 첫 화면에서 할 일이 한눈에 들어온다.

## 변형
- a: 기준. 지금 배치.
- b: 돈 패널이 비어 있으면 한 열(48rem)로 접고 제목도 같은 폭에 맞춘다. 패널에 내용이 생기면 원래 두 열.
- c: b + 분야 단추를 키우고(높이 2.75rem) 칸 간격을 넓히고 제목을 크게, 밑줄을 둔다.
- d: a의 두 열 배치 그대로 + c의 모양(단추 크기·간격, 제목 크기·밑줄). 사용자 요청으로 추가.

## 측정
- 자동: 폭 1920·1280·390에서 제목 왼쪽 x 와 분야 선택 왼쪽 x 의 차이, 첫 화면(스크롤 없이)에 보이는 분야 단추 수, 단추 최소 높이.
- 사람: 시작 화면에서 "무엇을 하는 곳인가"와 "어디를 누르나"가 바로 보이는가.

## 반응
- 2026-10-14 자동 측정(Chrome 1920px, 돈 패널 비어 있음): 제목 왼쪽 x 와 분야 선택 왼쪽 x 의 차이 a=352px, b=0, c=0. 분야 단추 최소 높이 a=40px, b=40px, c=44px. 스크롤 없이 보이는 단추는 세 변형 모두 26/26. 1280·390px 측정과 사람 반응은 아직.
- 2026-10-14 vitest 717건·typecheck·validate 통과(대비 토큰은 건드리지 않음).
- 2026-10-14 사용자: "a와 c를 조합하는게 좋겠다. b의 경우 자금카드가 옆으로 튀어나와서 보기 안좋다." → b·c 의 열 접기는 돈 카드가 생기는 순간 배치가 옆으로 튀므로 버리고, 열은 a 그대로 두고 c 의 모양만 얹은 d 를 만들었다.

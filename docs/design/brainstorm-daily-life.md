# 일상(생활) 이벤트 문장 초안: Haiku 브레인스토밍 (#124, 2026-10-15)

사용자 요청(2026-10-15): 연구노트 피드에 일상 이벤트를 더하고, 브레인스토밍은 Haiku workflow로 한다. 이 문서는 **초안이며 감사 전**이다. 팩 파일과 화면 연결은 감사(Fable, `docs/prompts/judge-any.md`) 뒤 후속 PR에서 한다.

- 작성: Haiku 6명(범주당 1명, 범주당 20줄), 자동 거름: 길이 15~45자, 숫자 없음, 중복 없음 → 120줄 중 0줄 제외.
- 규칙: 선택지 없는 한 줄, 실제 인물·기관·브랜드 이름 없음, 원작 문장 복사 없음, `creative: true`. 설계 규칙(빈도·선택·재등장 간격)은 [brainstorm-random-lines.md](brainstorm-random-lines.md) §3을 따른다.
- 아직 안 한 것: 실명·원작 유사·어색함 감사, 단계(stage) 적합성 확인, 문장 간 어조 통일. 가족 관계를 전제하는 줄(아내·남편·손주·아이·딸·아들)은 `가족 전제` 표시를 달아 감사가 판정하게 한다.

# 픽셀 장면과 삽화 설계

8-bit 레트로 픽셀 그림으로 단계 배경과 사건 삽화를 화면에 넣는다. 시안 비교와 사용자 반응은 [실험 0002](experiments/0002-pixel-scenes.md)에 있고, 이 문서는 채택된 안 E(네 배치를 역할로 나눠 함께 쓰기)와 모바일 설계를 구현할 수 있게 정한다.

## 1. 목표와 범위
- 지금 삶의 단계(박사과정·경력·은퇴)를 배경 장면으로, 주요 사건을 픽셀 아이콘으로 보인다. 그림은 정보를 더하는 보조이고, 같은 내용은 지금처럼 글자로도 남는다(색·그림만으로 뜻을 전하지 않는다, #61·#89).
- 사용자 결정(2026-10-15): 단계 배경과 사건 삽화 둘 다, SVG와 CSS로 직접 그림, 8-bit 레트로 스타일, 네 배치(A·B·C·D)를 역할로 나눠 함께 쓰는 안 E, 모바일은 따로 설계, 그림 설정(모두·간단히·끄기) 둔다.
- 엔진은 바꾸지 않는다. 그림은 `LifeState`와 기존 연구노트 기록(`notes()`)에서 정한다.
- 범위 밖: 소리, 캐릭터 꾸미기, 분야별 배경(뒤에 따로 논의).

## 2. 그림 자산
- 장면 3장: 박사과정(밤의 연구실: 창문과 달, 책장, 모니터 앞에 앉은 인물), 경력(낮의 연구 기관 건물 앞, 가방 든 인물), 은퇴(노을 지는 공원 벤치). 가운데 96×40칸 그림 + 좌우로 늘어나는 바탕(벽·하늘·바닥). 같은 장면을 세 가지로 잘라 쓴다: 넓은 장면(160칸), 초상(인물 중심 48칸), 모바일 상태 줄 초상(24×24칸).
- 아이콘 9개(12×12칸): 별(합격·승진), 찢긴 종이(실패), 모래시계(휴학), 학사모(학위), 가방(채용), 편지(소식), 갈림길 표지(결정), 시작(입학), 깃발(마무리: 은퇴·기록 종료).
- 실제 기관의 건물·로고·문장을 본뜨지 않는다(0004). 그림은 이 저장소에서 새로 그린다(0002).
- 그림 지도는 문자 배열(한 글자 = 한 칸, `.` = 빈칸)과 사각형 목록으로 둔다. 색은 글자 → 색 토큰 표로만 정한다.

## 3. 색
- `style.css`에 `--px-*`(공용: 잉크·흰색·피부·머리·옷·해·빨강·나무·잎·책 3색·의자)와 장면별 `--lab-*`, `--car-*`, `--ret-*` 토큰을 더한다. 밝은 `:root`와 어두운 블록 둘 다 정의한다. 어두운 테마에서는 장면이 밤 색으로 바뀐다(시안 0002 값을 출발점으로 한다).
- 그림 안에는 글자를 넣지 않는다. 장면 위에 얹는 글(대화 상자, 알림 막대)은 기존 `--fg`/`--bg`를 쓰므로 기존 대비 검사가 그대로 덮는다.
- 그림 색은 비글자라 대비 검사 대상이 아니지만, 쓰인 토큰이 두 테마에 모두 정의돼 있는지는 시험한다.

## 4. 배치(안 E)
화면 폭 기준은 지금 두 열 배치가 켜지는 64rem이다. 장면은 한 화면에 하나만 크게 나온다(큰 사건 장면이 떠 있는 동안은 예외).

| 역할 | 넓은 화면(≥64rem) | 좁은 화면(<64rem, 모바일 설계) |
|---|---|---|
| 지금 상태 | 왼쪽 칸 자금 카드 위 초상 창(D). 인물 위 말풍선에 최근 사건 아이콘, 아래 한 줄에 그 사건 문장 | 위 고정 상태 줄: 24칸 초상, 단계 문장(`statusLine`), 나이·진행 기간·현금. 내려도 위에 남는다 |
| 사건 종류 | 연구노트·삶의 정리 줄마다 아이콘(B). 지금의 글자 표지는 화면에서 숨기고 화면 낭독기용으로 남긴다 | 같음 |
| 분위기 | 본문 바깥 여백에만 단계 풍경(C): `html` 배경은 장면 하늘·벽 색, 화면 아래에 넓은 풍경 띠를 고정하고 본문(`body`)은 불투명 | 없음 |
| 큰 순간 | 큰 사건이 생긴 달에 연구노트 위에 넓은 장면(A)과 대화 상자. 닫기 단추. 다음 진행 때 접힌다 | 같음, 폭만 좁게 |
| 최근 사건 문장 | 초상 창 아래 한 줄 | 화면 아래 고정 알림 막대(아이콘 + 문장). 같은 문장이 연구노트에 글자로 있으므로 막대는 `aria-hidden`이고 새 낭독 영역을 만들지 않는다 |
| 자금 카드 | 지금처럼 펼침 | 접힘(`<details>`), 요약 줄에 현금 |

- 자금 카드의 접힘 상태는 처음에는 화면 폭을 따르고(좁으면 접힘, 넓으면 펼침), 그 뒤로는 다시 그리거나 화면 폭이 바뀌어도 사용자가 마지막으로 둔 대로 남는다(#153).
- 단계 → 장면: `phd` → 박사과정, `career` → 경력, `retired` → 은퇴, `end` → 기록에 은퇴가 있으면 은퇴, 경력이 있으면 경력, 아니면 박사과정. `pre`(시작 전)에는 그림이 없다.
- 기록 → 아이콘: 연구노트 키로 먼저 정하고(`log.qual-pass`·`log.promotion` 별, `log.defense-pass`·`log.degree`·`log.end-degree` 학사모, `log.hired` 가방, `life.start` 시작, `log.retired`·`log.end-age80` 깃발), 나머지는 종류(`NoteKind`)로 정한다(good 별, bad 찢긴 종이, leave 모래시계, news 편지, decision 갈림길). `scene`·`plain` 줄에는 아이콘이 없다. 새 키(예: #84의 `log.laid-off`)는 종류를 따라간다.
- 큰 사건: `life.start`, `log.degree`, `log.hired`, `log.retired`, `log.end-*`. 자동 진행 4× 이상에서는 큰 장면을 띄우지 않고 초상 말풍선만 바꾼다(번쩍임 방지).

## 5. 그림 설정
- 제목 아래 한 줄에 "그림: 모두 / 간단히 / 끄기"(제목 밑줄이 전체 폭이라 같은 줄에 두지 않는다). 기본은 모두. 간단히 = 아이콘(B)만, 끄기 = 그림 없음(지금 화면과 같음).
- `<html data-art="full|lite|off">`로 CSS가 숨긴다. 선택은 localStorage `aphd-art`에 남기고, 읽기·쓰기 실패 시 기본값을 쓴다.
- 움직임 줄이기 설정(`prefers-reduced-motion`)이면 말풍선·커서 깜빡임을 끈다.

## 6. 코드 구조
- `web/src/pixel.ts`(DOM 없음): 그림 지도, `sceneOf(s)`, `iconOf(note)`, `isBigEvent(textKey)`, `sceneSvg(stage, crop)`, `iconSvg(icon)`이 SVG 문자열을 돌려준다. 장면·자르기별로 결과를 캐시한다.
- `main.ts`: 초상 창·상태 줄·큰 장면·알림 막대 렌더, 피드와 삶의 정리에 아이콘. 넓은·좁은 구조를 둘 다 그리고 CSS 미디어 질의가 하나를 보인다.
- 문구(장면 설명 `aria-label`, 설정 이름, 닫기)는 `strings.ko.ts`에 둔다. `index.html`에는 한글을 넣지 않는다(0001).
- 장면 SVG는 `role="img"`와 장면 설명, 아이콘은 `aria-hidden`이고 옆의 글자 표지가 뜻을 전한다.

## 7. 시험
- `pixel.test.ts`: 모든 그림 지도의 행 길이가 같고 정해진 글자만 쓴다. 모든 `NoteKind`·큰 사건 키가 아이콘을 받는다(`scene`·`plain` 제외). `sceneOf`가 다섯 단계 모두를 처리한다. SVG에 색 리터럴이 없고 `var(--…)`만 쓴다.
- `a11y.test.ts` 확장: 그림이 쓰는 모든 토큰이 밝은·어두운 블록에 정의돼 있다. 대화 상자·알림 막대 글자가 `--fg`/`--bg`를 쓴다.
- 화면 확인: Chrome으로 넓은 화면·390px 폭 × 세 장면 × 두 테마, 큰 사건 한 번, 그림 설정 세 가지. 결과는 PR 본문과 실험 0002 반응에 남긴다.

# 0003. 공개 학술지·학회 지표만 사용

## 상태
승인됨 · 2026-10-13

## 맥락
게임은 target journal·conference와 영향력 지표를 쓰려 한다. 가장 흔한 지표인 Journal Impact Factor는 Clarivate의 유료 데이터베이스(JCR)에 속하며 재배포가 금지된다. 공개 대안으로 Scimago Journal Rank(SJR, 사분위 Q1~Q4 공개), CORE 학회 등급(A*/A/B/C 공개), 한국연구재단 KCI 등재 여부(공개)가 있다.

## 결정
venues 팩은 저널에 SJR 사분위와 KCI 등재 여부, 학회에 CORE 등급만 기록한다. JCR 영향력 지수는 수집하지도, 표시하지도 않는다. 게임 내 "영향력"은 사분위·등급에서 유도한 서수 척도로 표현한다. 공개된 채택률(학회 홈페이지 공지)은 출처와 함께 기록한다.

## 결과
얻는 것: 재배포 가능한 데이터, 한국 인문사회 저널(KCI)까지 한 체계로 커버. 잃는 것: 플레이어에게 익숙한 "IF 숫자"는 노출하지 않음. 다시 볼 조건: 공개 라이선스의 저널 지표가 새로 나올 때.

## 결정
**#62를 그대로 둔다: 유예 3개월 + 3개월, 판정 기준은 현금 잔액 음수, 종료는 결정론적.** 이 기록이 잰 다섯 종류의 대안(유예 연장 5벌, 월 순현금흐름 부호 기준, 순현금흐름 비례 월 위험률, 위기 개월 비례 월 위험률, 종료 없음)은 어느 것도 연간 이탈 통과 칸을 0/4에서 움직이지 않거나(유예 24개월에서만 1/4), 자연·공학 휴학 칸과 공학 학위 기간 칸을 틀린 방향으로 밀거나, 재정 파탄 건수를 거의 바꾸지 않는다(순현금흐름 기준 341 → 334, 위험률 348·358). 재정 파탄의 건수는 종료 규칙이 아니라 위기 진입(일반 대출 한도 소진 45~60개월, 그 뒤 월 순현금 B −31~−52만 / C −47~−61만 / D +30만)에서 정해진다: 종료를 아예 없애도 D의 12개월 안 회복은 52%, B·C는 9~11%다. 그래서 #62는 0021 조건의 손잡이가 아니고, 남는 손잡이는 위기 진입 쪽(자비 경로의 수입 구성과 근로, #166·#167이 다루는 정책·표식, 가족 지원)이다. 어떤 완화든 학위 기간 칸에 같은 부작용을 낸다: 종료를 없애거나 한도를 없애면 살아남는 삶이 느린 삶이라 자연 학위 기간 중앙값이 6.0 → 6.5년으로 상한(6.0)을 넘고 공학 6.5는 그대로다 — 재정 파탄을 줄이는 손잡이는 이 칸을 같이 봐야 한다. 0014 #9와의 관계: #9는 공식 확률의 바닥·천장이지 결정론적 종료의 금지가 아니며(재학연한·자격시험 3회·휴학 상한이 같은 종류다), 0005의 요구("원인을 선택에서 찾는다")는 D 25% 대 B·C 7~10%로 약하게나마 충족되고, 잰 위험률 규칙은 그 차이를 키우지 않았다(시간 비례 위험률은 18% 대 8%로 오히려 줄인다). 새 0014 행은 없다. 0021 "다시 볼 조건"의 플레이테스트 피드백 항목은 그대로 열어 둔다 — 이 기록은 "측정으로는 바꿀 근거가 없다"는 판정이지 "벽이 아니다"라는 판정이 아니다.

## 결과
얻는 것: 0021 (b) 손잡이가 닫히고(0023 선택지 규칙 + 이 기록 종료 규칙), 재정 파탄 목표의 남은 손잡이가 위기 진입 쪽으로 좁혀진다. #62의 사유 칸에 측정 근거가 생긴다(지금은 "세부가 없어 설계"뿐). 유예 길이가 사실상 이자 없는 추가 신용이라는 점이 기록되어 #61 판정(0021)과 같은 기준으로 묶인다.

잃는 것: 재정 파탄 비율은 이 기록으로 움직이지 않는다(34.1% 그대로). 위기 결정에서 B·C를 고른 플레이어는 거의 확실히 3개월 뒤 끝나고, 그 사실을 화면이 알려 주지 않으면 벽으로 느낄 것이다 — 완화는 종료 규칙이 아니라 결정 화면의 확률 힌트(0005 "통계에서 유도한 확률 힌트")로 한다(아래 "변경"의 design 세션 항목).

다시 볼 조건: (1) 플레이테스트에서 재정 종료가 벽처럼 느껴진다는 피드백(0021 그대로). (2) 박사과정 재정 위기 대응 행동 레코드(휴학·근로·대출·이탈 비율)가 들어오면 #62의 3+3과 #36의 200만을 그 값으로 다시 본다. (3) 위기 진입 쪽 손잡이(#166·#167, 자비 경로 수입 구성, 직장 병행 판정)가 반영된 뒤 0021 조건값이 여전히 2배 넘게 남으면, 그때 #62가 아니라 #49의 0.5 몫과 #61을 다시 본다(재정 중립 측정에서 사회·공학의 연간 이탈이 레코드 하한 아래이므로 0.5 몫을 올리면 재정 파탄의 예산은 더 줄어든다 — Wave 6 회고 체크리스트 "#49 0.5 → 약 0.7" 후보와 상충하는 방향임을 적어 둔다). (4) D 뒤 재위기 비율(5단계 §3: 위기 D 14.6%, 모든 원인의 D 23.2%, 기간 제한 없음; 이 기록의 유예 연장·순현금 기준 실행에서는 15개월 안 52~55%)이 플레이에서 "휴학해도 소용없다"로 읽히면 D의 휴학 12개월·200만(#36)을 별도 판정한다.

### 판정 근거
- **(1) 유예 연장은 #61 인상과 같은 기제다.** 출처 근거: 아래 측정 표 — 유예를 3+3에서 12+12로 늘리면 재정 파탄 34.1% → 20.5%이지만 재정 파탄 달 중앙값이 53 → 67개월로 밀리고 졸업이 48.7% → 61.1%로 는다. 0021이 #61 4,800만을 거절한 사유("한도 ÷ 월 대출이 졸업 중앙값을 넘어서는 것이 29.2%의 기제")와 같다. 설계 가정(산술): 한도 뒤의 음수 현금은 이자 없는 연체이므로 유예 n개월은 n × 월 적자만큼의 무이자 신용이다. 위기 삶의 월 순현금 중앙값 −31~−61만으로 유예 12개월은 약 400~700만, 24개월은 약 800~1,500만의 추가 신용이고, #61을 4,200만에서 4,800~5,400만으로 올린 3단계 훑기(29.2%·25.2%)와 같은 범위에 떨어진다. 연간 이탈 통과 칸은 3+6·6+3·6+6에서 0/4, 3+12·12+12에서 1/4(사회만)이고, 3+12에서 공학 휴학 0.105(상한 0.104)가 새로 실패한다.
- **(2) 월 순현금흐름 부호 기준은 건수를 거의 바꾸지 않는다.** 출처 근거: 결정 뒤 3개월 종료 판정을 "현금 < 0"에서 "현금 < 0 이고 그 달 순현금 < 0"으로 바꾼 실행에서 재정 파탄 341 → 334, 0021 조건값 0.078 / 0.062 / 0.090 / 0.062. 기제: B·C의 월 순현금은 구조적으로 음수(−52 / −61만)라 그대로 끝나고(최종 종료 84% / 89%, 중앙값 4개월로 1개월 늦어질 뿐), D는 휴학 12개월 동안 순현금 +30만으로 살아남지만 복학 뒤 적자가 돌아와 73%가 끝난다. 재위기(15개월 안 다시 위기 결정 또는 종료) B 45% / C 51% / D 52%, 위기 결정이 두 번 이상인 삶 25 → 130. 자연 휴학 0.128 → 0.134, 공학 휴학 0.099 → 0.102로 0023 (4)가 예측한 방향이다. 또 이 기준은 현금이 음수인 채 몇 년을 이어 가는 삶을 허용해 "채권자 없는 연체"를 길게 만든다 — (1)과 같은 정직성 문제다.
- **(3) 확률적 종료는 건수를 줄이지 않고, 시간 비례형은 선택의 효과를 지운다.** 출처 근거: 순현금 비례 위험률(월 종료 확률 = clamp(−순현금 ÷ 지역 생활비, 0.02, 0.95))에서 재정 파탄 348, D의 종료까지 중앙값 18개월(B·C 1개월), 휴학 칸 2/4(공학 0.105 실패). 위기 개월 비례 위험률(clamp(k/6, 0.02, 0.95))에서 358, 3개월 회복 D 18% 대 B 7.5% / C 10.3%(결정론 25% 대 9% / 10%). 설계 가정: 0005는 "원인을 선택에서 찾는다"를 요구하므로 선택과 무관한 시간 위험률은 0005에 더 나쁘고, 선택이 바꾸는 양(순현금)에 건 위험률은 결정론 규칙과 같은 결과를 더 느리게 낼 뿐이다. 두 위험률 모두 레코드가 없는 새 상수(바닥·천장·분모)를 둘 넘게 요구한다.
- **(4) 건수는 진입에서 정해진다.** 출처 근거: 종료를 없앤 실행(POST_CRISIS_MONTHS 무한, 한도 4,200만 유지)에서 위기 결정 뒤 12개월 안 회복 B 9.9% / C 10.7% / D 52.2%. 결정 때 현금 중앙값 B −216만 / C −261만 / D −200만, 다음 3개월 월 순현금 중앙값 B −31만 / C −47만 / D +29만. D가 −200만을 +30만으로 메우려면 6~7개월이 필요해 3개월 유예로는 24~25%만 회복하고(유예 6개월이면 37%), B·C는 유예가 얼마든 회복하지 못한다. 재정 파탄에 남는 예산 = [0.7·r − n, 1.3·r − n], r = `statistics-phd-dropout-rate-{계열}`(0.064 / 0.064 / 0.048 / 0.046), n = 재정 중립(일반 대출 한도 무한) 실행의 연간 이탈(0.046 / 0.031 / 0.037 / 0.031): 인문 [−0.001 ≈ 0, 0.037] · 사회 [0.014, 0.052] · 자연 [−0.003 ≈ 0, 0.025] · 공학 [0.001, 0.029](삶-년 분모가 실행마다 달라 근사). 0021 이정표 0.032 / 0.032 / 0.024 / 0.023은 네 구간 안에 있다. 지금 값은 예산 상한의 2.2 / 1.2 / 3.8 / 2.2배(인문/사회/자연/공학)이므로 위기 진입 자체를 그만큼 줄여야 하고, 종료 규칙은 진입을 바꾸지 않는다.
- **(5) #9·0005 해석.** 출처 근거: 0014 #9 값 칸 "0.02 / 0.95", 쓰이는 곳 "상태 §4". `tick.ts` 10단계의 재학연한 종료, `hazards.ts` 26~29행의 휴학 상한, 자격시험 3회 불합격 종료는 모두 확률 없는 종료다. 설계 가정: #9를 "모든 종료는 확률이어야 한다"로 읽으면 이 셋도 어긋나므로 그 독해는 채택하지 않는다. 0005의 요구는 (3)·(4)의 수치로 판단했다.
- **(6) 자연 계열의 실패는 #62의 것이 아니다.** 출처 근거: 종료 없음·재정 중립 실행에서도 자연 휴학 0.112~0.122(상한 0.105)와 학위 기간 6.5년(상한 6.0)이 실패한다. 자연의 재정 파탄 예산 상한은 약 0.025로 네 계열 중 가장 작다.

### 반대 근거
- **유지 반대 — 벽이 가혹하다:** 현실의 재정 위기는 미등록 제적·휴학·수료 이탈·가족 차입으로 갈리고 3개월 뒤 강제 종료는 그중 가장 가혹한 길 하나다(0014 #62 사유, 0023 반대 근거 (4)). 맞다. 그러나 잰 대안 가운데 그 가혹함을 줄이면서 통과 칸을 깨지 않는 것이 없고, #62 자체가 레코드 없는 상수라 "덜 가혹한 값"도 레코드가 없기는 같다. 가혹함의 체감은 결정 화면이 종료 조건과 선택지별 회복 확률을 보여 주는 것으로 다룬다(0023이 이미 "3개월 안에 현금이 0 이상이 되지 않으면 박사과정이 끝난다" 문구를 정했다).
- **유예 3+6 채택 안:** D의 회복이 24% → 37%로 올라 0005의 "선택이 결과를 바꾼다"가 더 분명해지고 재정 파탄은 1.5%p만 준다. 작은 변경이고 "벽의 시점" 효과도 작다(파탄 달 중앙값 53 → 55). 그러나 (a) 연간 이탈 0/4·0021 조건 0/4가 그대로라 0021이 #61에 건 시험을 통과하지 못하고, (b) 자연 휴학 0.128 → 0.132로 실패가 굳고, (c) B·C는 여전히 0%가 3개월 안에 끝나지 않을 뿐 77~86%가 6개월째 끝나므로 벽이 3개월 뒤로 옮겨질 뿐이며, (d) 레코드 없는 상수를 레코드 없는 체감을 위해 바꾸는 일이라 0021의 사유와 어긋난다. 플레이테스트 피드백이 오면 이 안이 첫 후보다.
- **순현금흐름 기준 채택 안:** "선택한 길이 적자를 멈추면 살아남는다"는 규칙이 0005의 인과를 가장 직접 구현한다. 그러나 측정에서 살아남는 것은 D의 휴학 12개월뿐이고(그 뒤 73% 종료), 재위기가 45~52%로 늘어 플레이어는 같은 결정을 두세 번 반복한다. 휴학 칸도 틀린 방향이다. 또 음수 현금이 수년 이어지는 상태를 허용한다.
- **확률적 종료 채택 안:** "숫자는 확률을 올릴 뿐"이라는 원리에 글자 그대로 맞는다. 그러나 (3)대로 건수를 줄이지 못하고 선택의 효과를 키우지 못하며 새 상수가 둘 이상 필요하다. #9의 값(0.02/0.95)은 그 상수의 바닥·천장만 정해 줄 뿐 형태를 정해 주지 않는다.
- **휴학·석사 수료 이탈로 유도하는 안:** 0023 (4)의 반대가 그대로다 — 석사 수료 이탈은 연간 이탈 분자 안의 이름 바꾸기(§4.6, 0014 #45), 강제 휴학은 자연 휴학 칸(0.128)과 공학 학위 기간(6.5)을 틀린 방향으로 민다. 이 기록의 순현금흐름 실행이 "휴학으로 유도"의 효과를 사실상 보여 준다(D 생존 → 휴학 ↑ → 재위기).
- **"측정 없이 유지"가 아니라 "측정했으니 유지"라는 점에 대한 반대:** 모의실험의 선택 분포는 자동 정책(0014 #46, B 0.6 / C 0.2 / D 0.2)이라 사람 플레이어의 D 선택 비율이 다르면 결과도 다르다. 맞다. 그러나 0016 §3 (a)가 보정 측정 대상을 자동 정책으로 정했고, 선택지별 회복률(B 9% / C 10% / D 25%, 종료 없음에서도 10% / 11% / 52%)은 선택 분포와 무관한 조건부 값이다.

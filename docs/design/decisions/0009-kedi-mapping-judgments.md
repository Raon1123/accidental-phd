# 0009. KEDI 학과 분류 ↔ NRF 코드 매핑 판정

## 상태
승인됨 · 2026-10-13 (issue #2, 판정자 fable/main thread)

## 맥락
수집자(sonnet)가 한국교육개발원(KEDI) 「학과(전공) 분류 자료집」 4년제 대학 표(U 코드) 125개(대계열 7·중계열 35·소계열 83)를 NRF 학술표준분류에 매핑해 236행을 만들고 51개 코드·87행에 `needs-judge`를 붙였다. 쟁점은 다섯 가지였다.
1. primary 수준: 결정 기록 0007·0008은 "소분류 우선"인데, KEDI 소계열(예: 수학)은 학문 전체라 소분류 하나(수학일반)로 두면 통계가 다른 소분류 전공자를 놓친다.
2. 계열 불일치: KEDI 인문·자연·공학 계열 단위가 NRF 복합학·농수해양학·의약학(계열 기타)에 대응(문헌정보학, 조경학, 농림·수산, 동물·수의학 등 7건).
3. 병합 단위의 임의 primary: 금융·회계·세무학, 에너지공학, 반도체·세라믹공학, 천문·기상학, 무용·체육, 연극·영화.
4. 교양·응용 catch-all 코드: NRF 대응 없음.
5. 교육계열: NRF에 교육 대분류가 없음.

## 결정
- **primary 규칙(이 매핑에 한정).** primary = KEDI 단위 전체를 담는 가장 좁은 NRF 코드. 중분류·대분류도 허용한다. 횡단 후보는 보조 행(primary=false)으로 남긴다. NRF→KEDI 조회는 primary nrf_code가 조상인 행 가운데 kedi_level이 가장 깊은 것을 쓴다. 대분류에 둔 10건(U0101, U0102, U0201, U0203, U0406, U0501, U0502, U0504, U0601, U0604)은 집계 전용이며 접두어 매칭으로 쓰지 않는다(U0203→B000000은 경영·경제·법을 과포함). 0007의 "소분류 우선"은 세부전공 선택지(트랙 매핑)에만 적용한다.
- **계열 불일치 7건.** 매핑은 그대로 둔다(NRF 기준으로 정확함). 게임 계열은 NRF 대분류에서 유도(0007)하므로 문헌정보학(H030000), 조경학(F030000), 농림·수산(F000000), 농업학(F010000), 수산학(F050000), 산림·원예학(F020000), 동물·수의학(F040000)은 1차 선택지 범위 밖이다. 교육·의약·예체능 12건과 합쳐 계열 `기타` primary 19건이 범위 밖이다. 통계 집계에는 계속 쓴다.
- **병합 단위.** 수집자 선택을 승인한다: 금융·회계·세무학→B060000 회계학, 에너지공학→D020700(트랙 energy와 동일), 반도체·세라믹공학→D100000 재료공학(세라믹 포함; 트랙 semiconductor D120100과 다르며 통계는 두 쪽에 모두 참고), 천문·기상학→C050000, 무용·체육→G100000, 연극·영화→G080000. 보조 행이 나머지를 가리킨다.
- **교양·응용 catch-all.** 일반·기타 코드로 둔다(U010112→A220000, U010208→A990000, U020107·U020308→B010000, U041102→D990000, U041103→D010000, U050304→C120000, U050406→C010000). 박사과정 모집 단위가 거의 없어 영향이 작다. confidence `assumed` 유지.
- **교육계열.** U03→B120000 교육학, U0305→B121200 교과교육학. 교과교육은 각 학문 코드에도 흩어지므로 교육계열 통계는 교육학 중분류로만 집계한다.
- 나머지 판정 보류 행(가족·사회·복지학, 국제학, 도시·지역학, 도시공학, 광학공학, 정보·통신공학, 기전공학, 자원학, 환경학, 지구·지리학, 생명과학/생물학 동일 코드 등)은 수집자의 primary를 승인한다. 모든 행의 `needs-judge` 표기를 지우고 "판정 2026-10-13 (결정 기록 0009)"를 note에 남겼다.

## 결과
얻는 것: KEDI 교육통계(statistics 팩)를 NRF 코드로 조회할 수 있고, departments 팩(241개)이 KEDI 소계열을 통해 통계와 이어진다. 잃는 것: 출처가 2020년판 자료집(2023년판 원본 미확보, 2024년 제3자 사본으로 코드 불변 확인)이라 개정 시 재대조 필요; 교양·응용 catch-all은 `assumed`. 다시 볼 조건: KEDI 2023년판 원본 확보, departments 팩 수집(#5)에서 매핑에 없는 KEDI 코드가 나올 때, 의약·농수해양 계열을 범위에 넣기로 할 때.

# 0007. 분류 기준은 한국연구재단 학술연구분야분류, 계열은 대분류에서 유도

## 상태
승인됨 · 2026-10-13 (Wave 1, issue #1~#3)

## 맥락
세부전공 선택지와 학과·저널·급여·통계 팩을 하나의 분류로 묶어야 한다. 후보는 세 가지였다.
- 한국연구재단(NRF) 학술연구분야분류: 대·중·소분류 코드. 연구과제·연구자 정보(KRI)·학술지(KCI) 모두 이 코드를 쓴다. 국가 기관이 고시하고 개정 이력이 공개된다.
- 한국교육개발원(KEDI) 교육통계 학과(전공) 분류: 대학 학과 통계(입학·졸업·교원)의 기준. 학과 단위라 모집 단위(departments 팩)와 잘 맞지만, 연구 분야·저널과는 직접 연결되지 않는다.
- 어쩌다 박사 v3.5의 6개 분야 × 26개 트랙: 게임용 창작 분류. 출처가 없고 국가 통계와 연결되지 않는다.

사용자 요구: "세부전공 리스트도 적절히 국가에서 제공하는 분류 체계를 따를 수 있도록 한다", "인문사회계열과 이공계열을 분리".

## 결정
- 기준 체계는 NRF 학술연구분야분류다. 세부전공 선택지는 중·소분류 코드와 한글명을 그대로 쓴다. 게임이 코드를 새로 만들지 않는다.
- KEDI 학과 분류는 `mapping-kedi.json`으로 NRF에 매핑한다(1:N 허용, `needs-judge`로 판정). 교육통계 수치(statistics 팩)는 KEDI 코드로 수집하고 이 매핑을 통해 NRF 코드로 조회한다.
- v3.5 트랙 26개는 `mapping-tracks.json`으로 NRF 소분류에 매핑한다. 트랙은 서사·연구 방법 태그로만 쓰고 분류 축으로 쓰지 않는다.
- 계열은 NRF 대분류에서 유도한다: 인문학·사회과학 → 인문사회, 자연과학·공학 → 이공. 의약학·농수해양학·예술체육학·복합학은 1차 범위 밖이며 `기타`로 표시하고 선택지에 넣지 않는다. 복합학 소분류 중 인문사회·이공에 속하는 것(예: 과학기술학, 인지과학)은 Wave 1 판정에서 개별 결정한다.
- 레코드 note에 `계열 <인문사회|이공|기타>`를 적어 UI와 엔진이 대분류 코드를 다시 해석하지 않게 한다.

## 결과
얻는 것: 저널(KCI)·연구과제·학과·통계가 한 코드로 이어짐, 선택지가 국가 분류와 일치, 개정 시 코드만 갱신. 잃는 것: 의약학·예체능 연구자는 1차 범위에서 빠짐, NRF 개정 시 매핑 두 개를 다시 봐야 함. 다시 볼 조건: NRF 분류 개정 고시, 또는 Wave 6 플레이테스트에서 의약학 계열 요구가 나올 때.

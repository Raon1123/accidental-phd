# 0002. fork 대신 재구현

## 상태
승인됨 · 2026-10-13

## 맥락
어쩌다 박사 v3.5는 배포된 JS만 읽을 수 있고 소스 repo에 접근할 수 없다. 배포본에는 라이선스 표기가 없다. 배포본 구조는 "전공만 선택, 나머지는 운"이라 이 프로젝트의 핵심 요구(선택이 삶을 바꾼다)와 맞지 않는다. 조사 결과는 [v3.5 oracle](../../oracle/v35-recon.md)에 있다.

## 결정
친구 코드를 복사하지 않는다. v3.5에서 가져오는 것은 공식·수치·모듈 구조에 대한 관찰뿐이며 `docs/oracle/v35-recon.md`에만 기록한다. 엔진은 Wave 3 스펙에서 새로 설계하고 Wave 4에서 새로 구현한다. v3.5 공식은 Wave 4의 스냅샷 비교 테스트에서 "기준값"으로만 쓴다. 친구가 나중에 소스를 이 repo에 올리면 그때 별도 결정 기록으로 통합 방식을 정한다.

## 결과
얻는 것: 권리 문제 없음, 선택권 모델을 처음부터 설계. 잃는 것: 초기 플레이 가능 시점이 늦어짐. 다시 볼 조건: 친구가 소스를 라이선스와 함께 제공할 때.

# 0004. 학교 표시명 가상 유지

## 상태
승인됨 · 2026-10-13 · 실명 금지 범위를 저장소 기록 전체와 학술지·학회로 넓힘(사용자 결정 2026-10-14·15, issue #113) → [0018](0018-wave5-retro-rules.md) §2

## 맥락
어쩌다 박사 v3.5는 20개 실제 대학의 공시 등록금·지원 제도를 데이터로 쓰되, 화면에는 서월대학교·한국과제기술원(KQIST) 같은 가상 이름을 보여준다. 이 게임은 지도교수 유형, 재정 위기, 중도 이탈 같은 민감한 사건을 다루므로 실명 기관과 결합하면 명예·톤 문제가 생길 수 있다. 사용자가 이 관례 유지를 선택했다.

## 결정
데이터 팩(schools, departments, salaries)은 실명과 공식 출처로 기록한다. UI는 표시 직전에 실명을 가상 표시명으로 치환하는 함수 하나를 통해서만 이름을 내보낸다. 매핑 표는 `data/packs/schools/README.md`에 둔다. 화면·공유 카드·로그 어디에도 실명이 나가지 않도록 Wave 5 체크리스트에 검사 항목을 둔다.

## 결과
얻는 것: 데이터 정확성과 표시 안전성을 동시에 확보. 잃는 것: 플레이어가 실제 학교를 바로 알아보기 어려움(의도된 효과). 다시 볼 조건: 실명 표시를 원하는 공식 협력 기관이 생길 때.

## 맥락
쟁점: 재정 위기(선택권 스펙 §5.5: 일반 대출 한도 도달 + 현금 음수 3개월)가 강제로 여는 `funding-expiry` 결정 지점에서, 선택지 C "자비·대출로 버틴다"가 신용이 남지 않은 상태에서도 열려 있고, 과제·장학 삶은 B·C를 고르면 지금 받는 장려금보다 낮은 수입으로 바뀐다. C를 닫을지, 과제·장학 삶의 선택지를 바꿀지, 그것이 정책 변경인지 규칙 변경인지, 재정 종료 자체를 완화할지 정한다.

충돌하는 출처와 값:

- 선택권 스펙 §5.5(재정 위기와 종료): `debt ≥ loanLimit`이고 `cash < 0`인 달 3개월 → 강제, 다시 3개월 → `financial`. 결정 기록 0014 #62. 박사과정은 끝나지만 생애는 경력 단계로 이어진다(#85).
- 선택권 스펙 §5.4(대출): 새 대출은 `debt ≤ loanLimit`까지만. 엔진 `engine/src/phd/money.ts` `applyCashflow` 133~138행이 그대로다. 즉 위기 상태에서 "대출로 버틴다"는 C를 고르든 안 고르든 이미 불가능하다.
- 엔진 `engine/src/decide.ts`: `optionUnavailable`(109~118행)은 A를 `no-funding`(자비, 기한 없는 자금)·`already-tried`, D를 `leave-cap`으로 닫고 C는 닫지 않는다. `fundingExpiry` 239행: C는 원인(cause)과 무관하게 `fundingState`를 `{route:'self', monthly:0, tuitionWaiver:0}`로 바꾼다. 232~238행: B는 `route:'project'`로 조교(TA, teaching assistant) 레코드 월액으로 바꾼다. 219~231행: A는 성공하면 과제 `until + 24개월`·장학 기한 유지, 실패하면 `until = 이번 달`.
- 엔진 `engine/src/phd/triggers.ts` 74~82행: 원인 우선순위 crisis > scholarship-review > until. 위기 강제는 A~D 네 개를 모두 싣는다.
- 자동 정책 가중치(선택권 §4.4, 결정 기록 0014 #46): funding-expiry A 0.5 / B 0.3 / C 0.1 / D 0.1. `engine/src/policy.ts` 51~65행이 고를 수 없는 선택지를 0으로 두고 다시 정규화한다. 자비 삶은 A가 없어 B 0.6 / C 0.2 / D 0.2.
- 3단계 결과표(`docs/oracle/calibration-wave6-step3.md` §1, 부록): 재정 파탄 353건(35.3%). 처음 자금 경로별 파탄 과제 33.7% / 장학 36.8% / 자비 36.2%. 한도 도달 삶 46.6~49.4%. 박사과정 순현금흐름 중앙값 장학 −66만 / 과제 −50만 / 자비 −68만, 파탄 삶의 생활비 지출 181~184만. 과제 장려금 중앙값 110만(참여율 r로 배율), 장학 50만, 자비 0. 계열별 재정 파탄 ÷ 삶-년 0.089 / 0.069 / 0.094 / 0.067(인문/사회/자연/공학), 결정 기록 0021의 이정표 0.032 / 0.032 / 0.024 / 0.023.

## 결정
네 쟁점에 하나씩 판정한다.

(1) **스펙·구현 불일치가 아니라 §3.3의 설계 빈칸이다.** 구현은 §3.3 문장("C: 장려금 0", 신용 조건 없음)을 그대로 따르므로 0016 §2의 차이 감사 행이 아니다. 빈칸은 §3.3의 선택지 효과가 "기한 도달" 트리거를 전제로 쓰였고 §5.5가 같은 결정 지점을 "강제로 띄운다"고만 적어 자금이 아직 살아 있는 삶에서 각 선택지가 무엇을 하는지 정하지 않은 데 있다. 신용이 없는데 C가 "열려 있다"는 것 자체는 결함이 아니다 — 새 대출은 §5.4·`money.ts`가 C와 무관하게 이미 막는다. 결함은 둘이다: (a) C의 설명문("저축과 대출로 버티며")이 위기에서는 거짓이고, (b) C의 효과가 과제·장학 삶의 살아 있는 장려금을 0으로 만든다 — "버틴다"가 아니라 자금 포기다. 자비 삶에서 C는 지금도 효과가 없는 선택(장려금 0 → 0)이다.

(2) **선택지 효과는 원인(cause)이 아니라 자금 상태(`fundingExpired`)로 정한다.** 규칙:
- A(연장·재선발): 자금이 이번 달 끝나는 경우(`fundingExpired(s)` — 기한 도달과 장학 유지 실패를 모두 포함)에만 연다. 자비 경로·기한 없는 자금은 지금처럼 `no-funding`, 끝나지 않은 자금은 새 사유 `not-expiring`으로 닫는다. 근거: 끝나지 않은 자금에 대한 A는 현금 효과가 없고(성공해도 장려금은 그대로) 실패하면 `until`을 이번 달로 당겨 다음 달 장려금을 잃는다. 위기의 원인(현금)과 무관한 선택지가 가장 높은 가중치(0.5)로 걸려 있는 상태를 끝낸다. 결정 기록 0014 새 행 #138.
- B(조교·강의 근로 전환): 효과를 바꾸지 않는다(모든 경로·원인에서 열린다). 과제·장학 삶에서 수입이 낮아지는 것은 선택의 대가이고, 그 숫자(지금 장려금, 조교 월액 레코드)는 화면이 보여줄 수 있다. 가용 조건에 "조교 월액 ≥ 지금 장려금" 같은 효용 비교를 넣지 않는다(§4.4가 정책에서 기대 효용을 쓰지 않는 것과 같은 방향).
- C(버틴다): 자금이 끝났거나(`fundingExpired`) 자비 경로이면 지금처럼 자비 전환(장려금 0, 감면 0, `until −1`, 표지 없음). 살아 있는 과제·장학 자금은 `fundingState`를 바꾸지 않는다. 자비 경로를 유지가 아니라 전환으로 두는 이유: D 뒤의 자비 상태는 `monthly 200만`·`recordIds ['0014#36']` 표지를 남기고(`decide.ts` 243~245행) 그 표지가 있으면 이후 어떤 휴학에서도 `leave-work`가 지급되므로(`tick.ts` 120~122행), 옛 C가 하던 초기화를 자비 경로에서 그대로 둬야 자비 삶의 결과가 지금과 같다. 새 대출은 어느 경우에도 C가 열지 않는다(§5.4). 설명문은 원인이 위기이면 "대출 한도를 다 썼다. 3개월 안에 현금이 0 이상이 되지 않으면 박사과정이 끝난다"를 적는다. C를 닫지 않는다. 결정 기록 0014 새 행 #139.
- D(휴학하고 일한다): 바꾸지 않는다. 지금도 모든 경로에서 열리고 `leave-cap`(0014 #5, 36개월)으로만 닫힌다.

경로·원인별 효과 표(판정 뒤):

| 원인 | 경로 | A | B | C | D |
|---|---|---|---|---|---|
| 기한 도달 · 장학 유지 실패 | 과제·장학 | 열림(지금과 같음) | 조교 전환 | 자비 전환(지금과 같음) | 휴학 12개월 + 월 200만 |
| 재정 위기, 자금이 같은 달 끝남 | 과제·장학 | 열림 | 조교 전환 | 자비 전환 | 휴학 |
| 재정 위기, 자금이 살아 있음 | 과제·장학 | **닫힘 `not-expiring`** | 조교 전환 | **자금 유지** | 휴학 |
| 재정 위기 | 자비 | 닫힘 `no-funding`(지금과 같음) | 조교 전환 | 자비 전환 = 초기화(지금과 같음) | 휴학 |

재진입 확인: 위기 C가 자금을 유지해도 `until > month`(또는 `until < 0`)이면 `fundingExpired`가 거짓이고 결정 뒤 `crisisStage`는 `expiryDecidedSince`로 `none`이므로 달마다 다시 열리지 않는다. 자금이 끝난 경우에 C가 자비로 전환해야 하는 이유는 반대다: `route`가 과제인 채 `until`이 지나면 `checkTriggers`가 달마다 funding-expiry를 다시 연다. 자금이 살아 있는 삶이 나중에 기한에 닿으면 보통의 기한 도달 결정이 열린다.

(3) **규칙 변경이다. 정책 변경이 아니다.** A의 가용 조건과 C의 효과는 선택권 §3.3의 규칙이고 `decide.ts`가 구현한다. 0014 #46 가중치는 건드리지 않는다. 가용 선택지가 줄어 정책 분포가 다시 정규화되는 것은 `leave-cap`·`no-funding`이 이미 쓰는 기제다. 다만 그 정규화가 과제·장학 삶의 위기 결정 분포를 A 0.5 / B 0.3 / C 0.1 / D 0.1에서 B 0.6 / C 0.2 / D 0.2로 옮기므로(자비 삶은 B 0.6 / C 0.2 / D 0.2 그대로), 0016 §3 (d)의 보고에서 "정책 고정 + 규칙 변경" 행으로 적고, C 효과만 바꾼 실행과 A 가용 조건까지 바꾼 실행을 나눠 어느 쪽이 차이를 만드는지 읽는다.

(4) **재정 종료를 완화하지 않는다.** 자동 휴학 전환·석사 수료 이탈 추가·유예 기간 연장 모두 이 기록에서 채택하지 않는다. "휴학해서 일한다"는 이미 D로 플레이어의 선택이고(0005: 선택이 결과를 바꾼다), 강제 전환은 휴학 비율(자연 0.129, 이미 상한 위)과 학위 기간(공학 6.5년, 이미 상한 위)을 틀린 방향으로 움직인다. 위기에서 석사 수료 이탈로 내보내는 것은 `financial`을 `exit-master`로 이름만 바꾸는 일이다 — 둘 다 연간 이탈 비율(선택권 §4.6, 모든 경로 합)의 분자이고 경력 단계의 불이익도 같다(0014 #45) — 그래서 최종 관문은 움직이지 않고 결정 기록 0021의 이정표만 거짓으로 통과한다. §5.5는 이미 생애를 경력 단계로 잇는다(벽은 박사과정의 벽이지 생애의 벽이 아니다). 결정 기록 0021 "다시 볼 조건"이 #62의 재설계를 플레이테스트 피드백 뒤로 미뤘고, 이 기록은 그 순서를 지킨다. 정직성은 종료 규칙이 아니라 선택지 수준에서 지킨다: 수행 불가능한 선택지는 닫고(A), 설명문이 효과와 같게 하고(C), 종료 조건을 결정 화면에 적는다.

## 결과
얻는 것: 위기 강제 결정에서 네 선택지가 모두 실제 행동이다. 과제·장학 삶이 장려금을 지키면서 버티는 선택을 가진다(지금은 A 성공의 동전 던지기로만 가능하다). "다른 선택 보기"(0005)의 기준선이 생긴다. 규칙이 원인이 아니라 자금 상태를 보므로 트리거가 같은 달 겹쳐도 한 가지 뜻이다. 0014 #46 가중치는 그대로다.

잃는 것: 정책의 위기 결정 분포가 과제·장학 삶에서 바뀌므로 3단계 결과표와의 비교에 실행 두 벌이 필요하다. 재정 파탄 비율이 어느 방향으로 움직일지 이 기록은 예측하지 못한다(B 전환이 늘면 수입이 낮아지고 D가 늘면 구제가 는다). 새 사유 코드·문자열·장면 변형이 늘어난다.

다시 볼 조건: 전후 측정에서 결정 뒤 3개월 생존이 어느 선택지에서도 0에 가깝게 나오면(아래 산술이 그렇게 예상한다) 벽은 선택지가 아니라 #62의 유예 3개월·`cash < 0` 조건이고, 그때 #62를 별도 `needs-judge`로 올린다(0021 "다시 볼 조건"과 같은 항목, 측정값이 플레이테스트 피드백을 대신한다). B의 `route:'project'` 표지가 조교 월액에 참여율 배율(§4.7)을 걸고 성장 배수를 깎는 것이 측정에서 B 전환 삶의 수입을 레코드 월액 아래로 끌어내리면 B 효과를 별도 판정한다. 박사과정 휴학생 소득·휴학 사유 레코드가 들어오면 D의 200만(0014 #36)과 함께 이 표를 다시 본다.

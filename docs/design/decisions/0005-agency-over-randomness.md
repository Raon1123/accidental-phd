# 0005. 무작위보다 선택

## 상태
승인됨 · 2026-10-13

## 맥락
사용자 요구: "완전한 랜덤보다는 사용자가 어느 정도 선택을 할 수 있고, 그 선택에 따라 life가 바뀌는 것을 보여주고 싶다." 어쩌다 박사 v3.5는 전공만 고르고 나머지는 운이다. 1in8b.life는 매년 focus 선택과 나이별 결정 지점을 두면서도 "Higher numbers raise the odds; they never decide the outcome."라는 원칙을 지킨다.

## 결정
- 입학 전 선택 6종: 계열(인문사회·이공) → 전공군 → 세부전공(한국연구재단 학술연구분야분류 중·소분류 그대로) → 학교·학과(241개 박사 모집 단위까지) → 자금 경로(장학·과제·자비) → 지도교수 유형 선호. 모든 항목에 "운에 맡기기"를 둔다.
- 결정 지점 7종: 자격시험 직후, 첫 논문 판정, 자금 만료, 졸업 직전(학계·산업·공공·창업), 경력 5년, 경력 10년, 은퇴 전. 선택지는 2~4개, 각각 통계에서 유도한 확률 힌트를 보여준다.
- 인문사회와 이공 계열은 서사·사건·경력 경로 팩을 분리한다. 연구 방법과 자금 구조가 다르기 때문이다.
- 선택과 능력치는 확률을 바꿀 뿐 결과를 결정하지 않는다. 확률은 데이터 팩 레코드 id를 근거로 적고, 근거가 없으면 `confidence: assumed`로 표시해 UI에 "게임 설정"이라고 알린다.
- 시간강사·교수·연구원 채용은 공고 확률로 모델링하고, 매월 가상의 학문 분야 뉴스가 수요 계수를 몇 달간 올리거나 내린다. 뉴스는 창작이며 창작 표시를 한다.
- 선택의 효과를 보여주는 장치: 같은 seed로 결정 지점에서 다시 분기하는 "다른 선택 보기", 같은 통계·다른 선택의 "같은 해 입학한 동기 4명".

## 결과
얻는 것: 플레이어가 결과의 원인을 자기 선택에서 찾을 수 있음, 통계적 현실감 유지. 잃는 것: 결정 지점마다 확률 근거를 찾아야 하므로 Wave 2 수집 범위가 커짐. 다시 볼 조건: Wave 6 플레이테스트에서 선택이 결과를 거의 바꾸지 않거나 반대로 결정적으로 바꾼다는 피드백이 나올 때. 공식은 Wave 3 스펙에서 정한다.

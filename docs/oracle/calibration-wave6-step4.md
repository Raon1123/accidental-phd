N=1000 자동 생애, `engine/sim/calibrate.ts`, 같은 seed `cal0`–`cal999`. 결정 기록 [0022](../design/decisions/0022-self-funding-income.md)(입학 때 조교 추첨, 0014 #136·#137)를 3단계([calibration-wave6-step3.md](calibration-wave6-step3.md)) 위에 적용한 전후다. 0016 §3 (d) 형식으로 환경 변경과 정책 변경을 나눈다. **정책 변경은 없다**(0014 #46·#129 그대로). 환경 변경은 하나다: 자비로 확정된 삶이 확률 P_TA(레코드 `statistics-ta-income-living-cost-2015` 0.265)로 선택권 §3.3 B와 같은 조교 상태(월 수입 학교 조교 레코드 또는 40만 원 0014 #35, 의무 주 10시간, 기한 없음)를 얻는다.

- 0022 효과 추정(조교 삶 적자 −28 ~ −38만, 벽 110~150개월, 전체 파탄 약 320건)은 실측 −49만, 일반 대출 한도 ÷ 파탄 삶 월 대출 48개월, 338건으로 빗나갔다. 원인은 위의 대체 효과다.

## 3. 보고만 지표

- 입학 때 조교 비율(대 `statistics-ta-income-living-cost-2015` 0.265): 변경 후 전체 12.8%, 자비 경로 안 30.1%. 민감도 0.62에서 전체 26.1%, 자비 안 61.4%(민감도 실행의 결과표는 덮은 값 0.620을 기준으로 적는다). 조사의 26.5%는 대학원생 전체의 주변 비율이므로 모의 전체 비율(장학·과제 삶의 조교는 0)과 직접 비교할 값이 아니다.
- 근로 비율(대 `statistics-part-time-income-living-cost-2015` 0.172): 근로 설정이 1달 이상 있는 삶 변경 전 69.5% → 후 68.0% → 민감도 65.8%; 근로 달 ÷ 휴학 아닌 박사과정 달 37.4% → 36.5% → 34.9%. 조사의 17.2%보다 훨씬 높다. 근로는 자동 정책(#129)의 결과라 이 단계는 보고만 한다.

## 4. 데이터 변경과 판독

- 데이터 변경(과제 5): 레코드 추가 2건(`statistics-ta-income-living-cost-2015` 0.265, `statistics-part-time-income-living-cost-2015` 0.172, 둘 다 verified — 2026-10-15 출처 PDF 18쪽 그림 3.4를 다시 열어 막대 값을 확인), 기존 레코드 값 변경 0건, 원본 `statistics-family-support-living-cost-2015` note 문장 추가 1건·삭제 0건. 출처 그림의 항목 이름은 "TA, RA 또는 행정조교로서의 수입으로 충당"이라 행정조교를 포함한다(새 레코드 note에 적었다).
- 결정 기록 0022 본문 정정 후보: "조교 감면은 … korea·uos에만 붙는다"는 빠진 학교가 있다. #21 과제 규칙의 `ra` 토큰이 `schools-konkuk-all-scholarship-tuition-rate-ra`(0.5)에도 걸려 konkuk 조교 삶의 감면은 0.5다(코드 동작은 #21 그대로이고 0022 본문만 덜 적었다).
- 판독: 입학 때 조교 추첨은 재정 파탄을 35.3% → 33.8%로 줄였고 학위 기간·휴학·이탈·취업·수요 통과 칸을 하나도 바꾸지 않았다. 0021 조건은 닫히지 않는다(0022가 예상한 결과). 다음 손잡이는 0021·3단계 §4 순서대로 (b) 재정 위기 규칙 #62·§3.3 강제 만료, (c) 공학 논문 병목이고, 위 2절의 근로 시작 조건(#129)은 정책 판정 후보로 더한다.

### 측정 정의

- seed i = `newSeed(\`cal${i}\`)`, i = 0..N-1. `createLife({ auto: true })` 로 계열·트랙·학교·자금·지도교수를 모두 운에 맡긴다.
- 박사과정 결과(학위·dropout·residence·financial·exit-master)는 stage 가 `phd` 를 처음 떠나는 순간에 잡는다(석사 수료 이탈의 `end.reason` 은 은퇴 때 덮인다).
- 학위 기간 = 졸업 달 ÷ 12(입학 = 0개월), 졸업자만의 중앙값. 졸업자가 없으면 모의값 `—` 이고 실패로 센다.
- 휴학 비율(주 지표, 스냅샷) = 휴학 중인 달 ÷ 박사과정 달 수(휴학 달 포함). KEDI 레코드 휴학률이 휴학생 ÷ 재적생이라 같은 정의다.
- 창(12개월, 보조) = 입학부터 12개월 창마다 휴학 중인 달이 하나라도 있으면 1(마지막 창은 길이 비율로 가중) ÷ 박사과정 삶-년. 6·12개월 휴학이 여러 창에 걸리므로 스냅샷의 약 2.2 배다. 판정에는 쓰지 않는다.
- 연 이탈 비율 = 학위 없이 박사과정을 떠난 삶(dropout, residence, financial, exit-master) ÷ 박사과정 삶-년.
- 취업 = 첫 `log.hired` 달 ≤ 졸업 달 + 12(졸업 전 구직 채용·창업·임시직 포함). 석사 수료 이탈자는 분모에서 뺐다.
- 수요 계수 = 경력 단계 매달 `demand(state, route)` 평균. `advanceYear` 가 연말 상태만 돌려주므로 같은 newsSeed 의 `updateNews` 를 달마다 다시 돌리는 그림자 상태에서 뽑는다.
- 교수 경험 = 첫 `professor` 채용 달 ≤ 졸업 달 + 120. 참고값 = 졸업자 계열 구성으로 가중한 1 − (1 − h)^10 (h = 노동 §2.3 교수 연 채용 확률, 계속 구직한다고 본 개략 상한).
- 표본이 적은 칸은 n 을 함께 읽는다. 허용 범위는 0014 #52(`CALIBRATION_TOL`).

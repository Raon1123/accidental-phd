- 작성: 2026-10-13, 스펙 초안·엮기 역할(opus). 감사 반영(2026-10-13, fable; 0014 #58·#59·#87·#104).
- v3.5 공식의 출처는 [v3.5 정찰 기록](v35-recon.md)이다. v3.5는 이 공식들의 근거를 밝히지 않는다(정찰 기록 §Key formulas, "game assumptions, not sourced").
- 우리 공식은 [상태 모델 스펙](../superpowers/specs/2026-10-13-engine-state-design.md), [선택권 모델 스펙](../superpowers/specs/2026-10-13-agency-model-design.md), [노동시장·뉴스 스펙](../superpowers/specs/2026-10-13-labor-market-news-design.md)에 있다. 근거 열의 레코드 id는 [근거 색인](../superpowers/specs/2026-10-13-wave3-evidence-index.md), assumed 번호는 [결정 기록 0014](../design/decisions/0014-assumed-probabilities.md)를 가리킨다.
- 공통 차이: 우리 확률은 모두 `odds(p0, …) = clamp(σ(logit(p0) + Σβ·z), lo, hi)` 형태다(상태 스펙 §4). v3.5의 선형 합 + clamp를 로짓 합으로 바꾼 이유는 능력치가 극단일 때도 확률이 경계에 붙지 않고 완만하게 움직이게 하려는 것이다. 평균 능력치(50)에서는 기준 확률 p0가 그대로 나온다.

# Wave 6 보정 6단계: 재정 위기 유예와 종료 조건 판정의 측정 (2026-10-15)

이 문서는 결정 기록 [0024](../design/decisions/0024-crisis-grace-ending.md)의 입력이다. 이 판정은 저장소를 고치지 않고 임시 작업 폴더에서 돌린 모의실험이므로 엔진 값은 바뀌지 않았고, 5단계([calibration-wave6-step5.md](calibration-wave6-step5.md)) 이후의 "변경 후" 행은 없다. 표는 판정 때 잰 값을 옮겨 적은 것이다.

**일회성 측정 표시.** 유예 변형 5벌은 아래 "재현" 칸의 `npm run calibrate -- --seeds 1000 --override …`로 다시 돌릴 수 있다. 규칙 변형 3벌(순현금흐름 기준, 위험률 2종)은 `engine/src/phd/money.ts` 한 곳을 임시로 바꾼 일회성 실행이고 패치는 커밋하지 않았다. 그 행들은 아래 패치 설명으로만 재현할 수 있다.

## 2. 일회성 패치 설명

패치(일회성, `engine/src/phd/money.ts` `applyCashflow`의 위기 계수 블록과 `crisisStage`): 결정 뒤(`done`) 분기에서 (a) `postCrisisMonths = net < 0 ? postCrisisMonths + 1 : 0` (net = 이번 달 현금 − 지난달 현금; 한도에서는 새 대출이 없어 순현금흐름과 같다), (b)·(c) `postCrisisMonths += 1` 뒤 `draw(seed, 'hazard', month, 'financial') < p`이면 표지 `financialHit`를 세우고 `crisisStage`가 그 표지로 `financial-end`를 돌려준다, p는 표의 식, 지역 생활비는 `livingCost(school)`. 위기 진입(3개월, 강제 결정)은 모든 행에서 같다.

## 4. 읽기

읽기: (1) 재정 파탄 건수를 줄이는 행은 유예가 길어진 행뿐이고, 그 행들은 파탄 달 중앙값을 뒤로 밀어 졸업을 늘리는 #61 인상의 기제다(3단계 §2 #61 4,800만 29.2% · 5,400만 25.2%와 같은 범위). (2) 어느 행도 0021 조건 0/4를 움직이지 않고, 연간 이탈 1/4은 유예 12개월 이상에서만 나오며 그때 공학 휴학(3+12)이 새로 실패한다. (3) 결정 뒤 월 순현금은 선택지가 정하고(B −31~−52, C −47~−61, D +29~+34만) 유예·기준·위험률이 바꾸지 못한다. 종료가 없어도 B·C의 12개월 안 회복은 10~11%다. (4) D의 회복은 유예 6개월에서 37%, 12개월에서 52%까지 오르지만 복학 뒤 재위기가 52~55%라 종료가 미뤄질 뿐이다. (5) 자연 휴학·학위 기간, 공학 학위 기간 칸은 종료 없음·재정 중립에서도 실패하므로 #62의 칸이 아니다. (6) 재정 중립 연간 이탈(0.046 / 0.031 / 0.037 / 0.031)에서 역산한 재정 파탄 예산은 인문 [≈0, 0.037] · 사회 [0.014, 0.052] · 자연 [≈0, 0.025] · 공학 [0.001, 0.029]이고 0021 이정표는 그 안에 있다.

# Wave 6 보정 11단계: 자동 정책의 첫 초고 규칙 전후 (2026-10-22)

N=1000 자동 생애, `engine/sim/calibrate.ts`, 같은 seed `cal0`–`cal999`. 결정 기록 [0029](../design/decisions/0029-first-draft-rule.md)(issue #182 1단계)를 10단계 채택 행 (E1)+(E2)(엔진 동작은 커밋 7963945, main f52e1b1과 같음, [calibration-wave6-step10.md](calibration-wave6-step10.md)) 위에 적용한 전후다. 바꾼 것은 선택권 §4.4 자동 정책의 조건 하나다: 논문·초고가 하나도 없고 자격시험 미합격이며 재학 개월이 첫 응시 창(0014 #72, 12개월)에 닿았으면 기존 writeP 0.6으로 집필을 고른다. 새 상수는 없고 정책 가중치(0014 #46의 숫자), 근로 시작 조건(#129), 환경 상수(#41·#45 포함)는 그대로다. 그래서 0016 §3 (d) 형식의 행이 모두 "정책 변경" 절에 들고, "정책 고정 + 환경 상수 변경" 절은 비어 있다.

**판독 요약: 결정 기록 0029의 채택 조건 4(통과 칸이 10단계보다 떨어지지 않음) 중 취업 칸이 충족되지 않았다.** 취업 1/6 → 0/6(공학 0.683 → 0.740, 상한 0.725). 나머지 통과 칸(학위 기간 4/4, 휴학 3/4, 이탈 2/4, 0021 조건 1/4, 수요 14/14)과 재정 파탄·졸업 ±1.0%p 조건은 충족했다. 0029는 이 결과로 재판정을 기다린다(§4).

약어. M̄ = 선택권 스펙 §4.2의 "자동 진행 정책에서 g 외 배수들의 기댓값"(상수 `G_MBAR_INIT`, 0014 #45). w = 첫 초고 규칙의 집필 확률(채택안에서는 writeP 0.6). X = 첫 초고 규칙의 재학 개월 문턱(채택안에서는 0014 #72의 12). "합격 전 초고 삶" = 첫 초고 달이 자격시험 합격 달 이하이거나 합격 없이 초고를 만든 삶 ÷ 전체(같은 달이면 틱에서 포커스가 시험보다 먼저 정해지므로 합격 전 정책이 만든 초고다). 월은 입학 = 0. 4칸 값은 인문/사회/자연/공학 순서.

#### 측정 정의

- seed i = `newSeed(\`cal${i}\`)`, i = 0..N-1. `createLife({ auto: true })` 로 계열·트랙·학교·자금·지도교수를 모두 운에 맡긴다.
- 박사과정 결과(학위·dropout·residence·financial·exit-master)는 stage 가 `phd` 를 처음 떠나는 순간에 잡는다(석사 수료 이탈의 `end.reason` 은 은퇴 때 덮인다).
- 학위 기간 = 졸업 달 ÷ 12(입학 = 0개월), 졸업자만의 중앙값. 졸업자가 없으면 모의값 `—` 이고 실패로 센다.
- 휴학 비율(주 지표, 스냅샷) = 휴학 중인 달 ÷ 박사과정 달 수(휴학 달 포함). KEDI 레코드 휴학률이 휴학생 ÷ 재적생이라 같은 정의다.
- 창(12개월, 보조) = 입학부터 12개월 창마다 휴학 중인 달이 하나라도 있으면 1(마지막 창은 길이 비율로 가중) ÷ 박사과정 삶-년. 6·12개월 휴학이 여러 창에 걸리므로 스냅샷의 약 2.2 배다. 판정에는 쓰지 않는다.
- 연 이탈 비율 = 학위 없이 박사과정을 떠난 삶(dropout, residence, financial, exit-master) ÷ 박사과정 삶-년.
- 취업 = 첫 `log.hired` 달 ≤ 졸업 달 + 12(졸업 전 구직 채용·창업·임시직 포함). 석사 수료 이탈자는 분모에서 뺐다.
- 수요 계수 = 경력 단계 매달 `demand(state, route)` 평균. `advanceYear` 가 연말 상태만 돌려주므로 같은 newsSeed 의 `updateNews` 를 달마다 다시 돌리는 그림자 상태에서 뽑는다.
- 교수 경험 = 첫 `professor` 채용 달 ≤ 졸업 달 + 120. 참고값 = 졸업자 계열 구성으로 가중한 1 − (1 − h)^10 (h = 노동 §2.3 교수 연 채용 확률, 계속 구직한다고 본 개략 상한).
- 표본이 적은 칸은 n 을 함께 읽는다. 허용 범위는 0014 #52(`CALIBRATION_TOL`).

# 노동시장·가상 뉴스 스펙 (Wave 3, issue #19)

- 상태: 초안 · 2026-10-13 (스펙 초안·엮기 역할, opus). 감사(fable) 전.
- 범위: 교수 공고 확률 기준값의 유도, 비전임·시간강사·박사후·출연연·연구직 공무원·기업·창업·임시직 경로의 기준값, 공고 추첨과 채용 확률, 수요 계수, 가상 뉴스 목록과 창작 표시. 경로별 급여와 승진은 [선택권 모델 스펙](2026-10-13-agency-model-design.md) §9, 공통 확률 함수 `odds`·`hazard_month`와 난수 규칙은 [상태 모델 스펙](2026-10-13-engine-state-design.md) §4·§6에 있다.
- 근거 규칙: 레코드 id는 [근거 색인](2026-10-13-wave3-evidence-index.md)에서만 인용한다. 근거가 없으면 "assumed (결정 기록 0014 #n)"이다([결정 기록 0014](../../design/decisions/0014-assumed-probabilities.md)). 판정 규칙은 [결정 기록 0013](../../design/decisions/0013-wave3-pre-spec-judgments.md) §6·§7이다.
- 약어: KEDI(한국교육개발원), KSCED(한국표준교육분류), NRF(한국연구재단), KISTEP(한국과학기술기획평가원). 정의는 [용어집](../../workflow.md#용어집). 교원 통계의 "계열"은 교원 본인의 전공이 아니라 소속 학과의 KEDI 대계열이다(statistics README). 모든 교원 통계는 일반대학(`all`) 값이며 전체 고등교육기관(`allinst`) 값과 섞지 않는다.

## 1. 기호

| 기호 | 뜻 |
|---|---|
| `B_k` | 계열 k의 교수 공고 기준값(연). 신규 임용 ÷ 박사 학위 취득자 |
| `h_r,k` | 경로 r, 계열 k에서 평균 능력치의 구직자가 1년 안에 채용될 확률 |
| `m_r,k` | 월 채용 확률 = `hazard_month(h_r,k)` |
| `s0_r` | 공고 하나에 지원했을 때 평균 능력치의 채용 확률 |
| `π0_r,k` | 수요 계수 1일 때 월 공고 도달 확률 = `m_r,k / s0_r` |
| `D_r,u(t)` | 달 t에 경로 r, 플레이어 단위 u(계열·트랙·중분류)의 수요 계수 |

## 2. 교수 공고 기준값 (0013 §6)

### 2.1 전 분야 비율 다시 계산

```

2021: 5198 ÷ 16,420 = 0.3166
2022: 3653 ÷ 17,760 = 0.2057
```

### 2.3 기준값에서 구직자의 연 채용 확률로

`B_k`는 "한 해 신규 박사 1명당 교수 신규 임용 수"다. 한 해의 교수 구직자는 그해 학위 취득자만이 아니라 여러 해의 박사후·강사가 쌓인 집단이다. 또 신규채용에는 다른 대학에서 옮겨 온 교원이 섞여 있다. 그래서 평균 구직자의 연 채용 확률은 `B_k`보다 낮게 둔다.

```
h_professor,k = min(0.10, κ × B_k),   κ = 0.5   (상한 0.10은 감사 변경, 0014 #104)
```

κ = 0.5는 assumed (결정 기록 0014 #104). 기준점: v3.5의 교수 전환 연 9%(학계 근무 36개월 뒤). κ = 0.5이면 공학 0.0998, 자연 0.0887, 사회 0.0960, 인문 0.1586이고, 상한 0.10을 적용하면 인문은 0.10이 된다.

## 4. 공고 추첨과 채용

### 4.1 월 처리 (구직 중인 경로마다)

```
1. 공고 도달:  p_post = clamp(π0_r,k × D_r,u(t), 0.005, 0.60)
   u_post = draw(seed, "labor", t, "post:" + r)            # 상태 스펙 §6.2
   u_post < p_post 이면 공고 1건을 보여준다(가상 학교·기관 표시명).
2. 지원 결정: 플레이어가 지원·보류를 고른다. 자동 모드·동기는 지원한다.
3. 채용 추첨:
   s = odds(s0_r, β_skill·z(skill) + β_net·z(network) + γ_S·(min(S, 12) − S_ref) + γ_exp·[academicMonths ≥ 24], lo 0.01, hi 0.60)
   u_hire = draw(seed, "labor", t, "apply:" + r + ":" + n)
   u_hire < s 이면 채용. 다음 학기 경계 달(교수·강사) 또는 다음 달(그 밖)에 시작.
```

| 계수 | 교수·비정년 | 시간강사 | 박사후 | 출연연·공무원 | 기업 | 근거 |
|---|---|---|---|---|---|---|
| β_skill | 0.8 | 0.4 | 0.8 | 0.6 | 0.6 | assumed (결정 기록 0014 #115) |
| β_net | 0.6 | 0.6 | 0.4 | 0.3 | 0.5 | assumed (결정 기록 0014 #115) |
| γ_S (논문 점수 1점당) | 0.12 | 0.05 | 0.10 | 0.08 | 0.03 | assumed (결정 기록 0014 #115) |
| S_ref | 이공 4, 인문사회 2 | 같음 | 같음 | 같음 | 같음 | assumed (결정 기록 0014 #115) |
| γ_exp (학계 경력 24개월 이상) | 0.4 | 0.2 | 0 | 0.2 | 0 | assumed (결정 기록 0014 #115) |

- 경계 `p_post` 0.005·0.60과 `s` 0.01·0.60은 assumed (결정 기록 0014 #116). 어떤 능력치·뉴스 조합에서도 공고 도달과 채용이 확실해지거나 불가능해지지 않는다. 이것이 1in8b.life에서 상속한 "숫자는 확률을 올릴 뿐 결과를 결정하지 않는다"의 구현이다.
- 한 달에 같은 경로의 공고는 많아야 1건이다. 여러 경로를 동시에 구직하면 경로마다 따로 추첨한다.
- S는 선택권 스펙 §6.4의 논문 점수, `S_ref`는 졸업 요건을 막 채운 졸업생의 대략적 점수다(이공 2편 × 2점, 인문사회 T3 1편 1.5점을 올림).

## 5. 수요 계수와 가상 뉴스

### 5.1 수요 계수

```
D_r,u(t) = clamp( Π_{뉴스 j가 t에 유효하고 표적이 (r, u)를 덮음} (1 + e_j), 0.70, 1.30 )
```

- 뉴스가 없으면 1이다. 효과는 유효 기간 동안 일정하고 기간이 끝나면 사라진다(완만한 감쇠 없음).
- 여러 뉴스의 곱도 0.70–1.30으로 자른다 (결정 기록 0014 #117). 0013 §7의 "뉴스 한 건 −30% ~ +30%"를 합산 수준에서도 지키기 위해서다.
- 표적 판정: 뉴스의 표적은 game 계열, KEDI 계열, 트랙 목록, NRF 중분류 중 하나이고 경로 목록을 가진다. 플레이어 단위 u = (game 계열, KEDI 계열, 트랙, 세부전공의 상위 중분류)가 표적에 들고 경로 r이 경로 목록에 있으면 덮는다.

### 5.2 발생 규칙

```
매월(박사과정·경력 모두): u = draw(seed, "news", t, "arrive")
  u < 0.5 이면 뉴스 1건 발생 (월 1건 이하)
  종류 = 가중치 비례 추첨 (slot "news:type")
  효과 e = 종류의 범위에서 균등 추첨, 0.01 단위 반올림 (slot "news:size")
  기간 = 종류의 범위에서 정수 균등 추첨 (slot "news:months")
```

- 월 발생 확률 0.5는 assumed (결정 기록 0014 #118). 0013 §7의 상한(월 1건 이하, 전 분야 합산)을 지킨다.
- 동기(상태 스펙 §6.4)는 플레이어 seed의 뉴스를 함께 겪는다.

### 5.4 창작 표시 규칙

- 뉴스는 전부 창작이다(결정 기록 0005, 0013 §7). 화면의 뉴스 카드마다 "창작" 표시를 붙이고, 뉴스 목록 아래에 "가상 뉴스: 실제 사건·기관·인물이 아닙니다"를 적는다.
- 뉴스 텍스트(Wave 5 텍스트 팩)의 각 항목은 `{id, type, headline, body, creative: true}`이며 `creative`가 없으면 검증기가 거부한다(Wave 5 검증 항목).
- 실존 인물·기업·정당 이름을 쓰지 않는다. 정부 기관은 "정부", "한 부처"처럼 일반 명사로 쓴다. 학교 이름은 가상 표시명만 쓴다(결정 기록 0004).
- 뉴스 카드는 효과를 "이 소식은 ○○ 분야 ○○ 공고를 몇 달 늘린다·줄인다(게임 설정)"로 함께 보여준다. 효과는 assumed이므로 근거 표기는 항상 "게임 설정"이다.
- 로그(`log`)에 남는 뉴스 줄은 `creative: true`다(상태 스펙 §3.1).

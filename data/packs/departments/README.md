# departments 팩

**목적.** 20개교의 박사 모집 단위(학과·학부·전공·대학원) 483개(2027학년도 전기 모집요강 기준; 어쩌다 박사 v3.5의 241개 중 240개 확인, 243개 추가, GIST 수리과학과 1개 제외)를 공식 모집요강으로 기록하고, 각 학과를 taxonomy 팩의 한국연구재단(NRF) 학술연구분야분류 중·소분류 코드에 연결한다. 약어는 [용어집](../../../docs/workflow.md#용어집). 플레이어의 선택 단위가 학과까지 내려가므로 이 팩이 선택지 목록이 된다.

**1차 출처 계급.** 각 대학원 박사 신입생 모집요강(최신 학년도), 학과 홈페이지.

**id 규칙.** `departments-<school_id>-<slug>`. 예: `departments-snu-computer`. `value`는 1(존재 확인), `unit`은 `count`. `note`에 한글 학과명·모집 단위 종류·NRF 코드. 학과별 등록금이 학교 기본값과 다르면 `departments-<school_id>-<slug>-tuition` 레코드를 따로 둔다.

**수집 결과와 판정(2026-10-13, #5, 결정 기록 0011).** 범위는 483개 전부 유지(선택 단위를 학과까지 내리는 것이 목적). v3.5 단위는 slug 유지, 추가 단위는 트랙 slug에 `-2`, `-3`(이름은 note 첫 칸). 같은 학과가 두 트랙에 걸치면 단위를 두 개 두고 note에 `same_unit_as`. 학과명이 트랙 primary와 다른 NRF 중분류에 속하면(항공우주·조선·자동차·원자력·의공학·건축·전자/정보통신·정책학·영어학·고분자·생화학, 40건) 학과명에 맞는 NRF 코드를 쓰고 트랙은 가장 가까운 게임 트랙으로 둔다. 협동과정은 종류 `학과` 또는 `전공`으로 적고 note에 표시. 이번 차수 박사 미모집 3건(부산 심리, 경북 기계·철학)은 `indexed`. 학과별 등록금은 학교 기본값과 다른 7건만(서울대 3, 충남대 4). 수집자 메모가 note에 남아 있는 106건(추가 단위 중 트랙 판단이 들어간 것)은 Wave 5 선택지 노출 시 재검토.

# schools 팩

**목적.** 박사과정 20개교의 분야별 등록금·입학금·연구 지원 제도를 공식 출처로 기록한다. 어쩌다 박사 v3.5와 같은 범위다. 데이터는 실명, 화면 표시는 가상 이름(결정 기록 0004).

**1차 출처 계급.** 각 대학 등록금 공시(대학원 요람·입학 안내), 대학알리미(등록금 현황), 각 대학원 장학 규정. 약어는 [용어집](../../../docs/workflow.md#용어집).

**id 규칙.** `schools-<school_id>-<field>-<item>`. 예: `schools-snu-cs-tuition`, `schools-kaist-all-stipend-min`. `unit`은 `krw`(원) 또는 `krw-10k`(만원). 제도의 조건(선발형·보장형, 최대 학기)은 `note`에.

**수집 결과와 판정(2026-10-13, #4).** 206건(verified 202, indexed 4: POSTECH 등록금·입학금, 한양 BK21 장려금 등은 제3자·미확인 자료). 사립대 등록금(7.1~7.5M/학기)이 어쩌다 박사 v3.5 엔진의 분야별 범위(3.2~6.2M)를 넘지만, 그 범위는 엔진의 설계 가정이고 v3.5 schools.js의 실제 값(연세 7,342,000·고려 7,392,000·성균관 7,499,000·KAIST 9,559,000)과 수집값이 일치한다 → 실제 값을 쓴다(판정). 연도 차이: 한양·경희·서울시립·전남은 2024~2025 기준값이 섞여 있어 note에 연도 명시. cs 계열 소속을 공시하지 않는 학교(한양·서강·경희·부산·서울시립·이화)는 cs 레코드 없음 → Wave 3에서 공학 값으로 대체(assumed). 등록금은 학기당, 장학·장려금은 note의 기간 기준.
